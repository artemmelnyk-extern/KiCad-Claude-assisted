# PC817 24 V input bench

A two-channel test bench that lets a 5 V microcontroller (Arduino UNO R4 or R3) read 24 V signals
through PC817 optocouplers, with the 24 V side electrically isolated from the microcontroller.

The KiCad schematic in this repository is **generated by a Python script**. The script is the source;
the KiCad files are its output.

![Schematic](docs/pc817_bench.svg)

## The circuit

Each channel:

```
 INx_24V ──[2.2k]──[2.2k]──┬──[LED]──► PC817 pin 1      pin 4 ──┬── D2 / D3
                           │                                    │
                       [1N4148]                              [10k] ── +5V
                     (cathode up)
 GND_24V ──────────────────┴────────── PC817 pin 2      pin 3 ───── GND
```

| Ref | Part | Role |
|---|---|---|
| R1–R4 | 2.2 kΩ, ¼ W, two in series per channel | limit the input current |
| D1, D2 | red LED | lit when 24 V is present |
| D3, D4 | 1N4148 | protect the LEDs against a reversed input |
| U1, U2 | PC817 | isolation |
| R5, R6 | 10 kΩ | pull-ups to +5 V |

- 24 V present → the optocoupler conducts → the pin reads **LOW**.
- Input current: (24 V − 1.2 V − 2.0 V) / 4.4 kΩ = 4.7 mA.
- Each 2.2 kΩ dissipates 49 mW at 24 V and 75 mW at 28.8 V, 30 % of a ¼ W rating at most.
- `GND_24V` and `GND` are separate nets. Do not join them: that is the isolation.
- The PC817 LED tolerates only 6 V in reverse, hence the 1N4148.

## Repository layout

| Path | Content |
|---|---|
| `generate.py` | writes every file in `kicad/`. Standard-library Python 3, no dependencies |
| `kicad/` | generated KiCad project: open `pc817_bench.kicad_pro` |
| `docs/` | schematic exported as PDF and SVG |
| `firmware/pc817_two_inputs/` | Arduino sketch that prints every edge with its timing |
| `check.sh` | regenerate, run KiCad's electrical rule check, export `docs/` |

## Use

```bash
python3 generate.py     # rewrite kicad/
./check.sh              # the same, plus rule check and PDF/SVG export (needs kicad-cli, KiCad 8+)
```

With the Flatpak build of KiCad:

```bash
KICAD_CLI="flatpak run --command=kicad-cli --filesystem=$PWD org.kicad.KiCad" ./check.sh
```

To change the circuit, edit `generate.py` and run it again. Edits made in the KiCad editor are
overwritten by the next run.

## How the generator works

`generate.py` uses no KiCad API. It writes KiCad's text file format (S-expressions) directly:

- the symbols (resistor, LED, diode, PC817, input connector, Arduino UNO R4 WiFi) are defined in the script and embedded in the
  schematic, and also written to `kicad/bench.kicad_sym`;
- `place()`, `wire()`, `label()` and `junction()` append one schematic item each;
- `channel(k, y)` draws one complete input channel, and is called twice.

## Limits

- The schematic has **no footprints**: it describes a breadboard bench, not a PCB.
- The files are written in the KiCad 7 format. KiCad 8 and later open them and show a notice that the
  file will be converted when saved. Checked with KiCad 10.0.6: loads, 0 rule-check violations.
- The Arduino UNO R4 WiFi is drawn as one symbol with its header pins as printed on the board. Only
  5V, GND, D2 and D3 are used; the other pins carry no-connect marks. The symbol has no footprint.
- A single optocoupler channel cannot detect its own failure: a shorted output transistor reads as
  "24 V present". Do not use one channel alone for a safety function.

## Datasheet

PC817: 4-pin DIP, pin 1 anode, 2 cathode, 3 emitter, 4 collector; current transfer ratio 50–600 % at
5 mA; isolation 5000 Vrms. Datasheets are available from Sharp and from second-source manufacturers.
